# Leverage 1.0.2

Rename your recordings.

## Install

Download `leverage-1.0.2-setup.exe` and run it. It upgrades an earlier version in place and keeps your settings, keys, recordings and notes. Quit Leverage from the tray first.

The installer still isn't code-signed, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

## What's new

- **Rename recordings from the Library.** Click a recording's name to edit it. **Enter** or clicking away saves, **Esc** cancels, and an empty name is ignored. Names can be up to 200 characters.
- **Exports use the new name.** Export MP4 and Export GIF name the file after the recording, so a renamed recording exports as `Client demo.mp4` instead of `Recording 2026-10-23 11-32-52.mp4`.
- The recording's folder on disk keeps its date-based name, so the editor, transcripts and notes keep working after a rename.
