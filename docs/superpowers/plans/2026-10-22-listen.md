# Leverage Listen — Implementation Plan

> Steps use checkbox (`- [ ]`) syntax. Build natively with TDD: failing test → implement → pass → commit.

**Goal:** Dictation anywhere (toggle hotkey → pill → transcribe → optional cleanup → paste) and meeting
notes (record mic + system audio, or start from a Studio recording → transcript → AI summary).

**Spec:** `docs/superpowers/specs/2026-10-22-listen-design.md`; evidence: `docs/reverse-engineering/03-openwhispr.md`.

**Architecture:** The pill is a small non-focusable window whose renderer owns the mic MediaRecorder and
an AnalyserNode feeding the speech gate. On stop it sends the WebM bytes and the gate's verdict to main.
Main converts with ffmpeg, transcribes with the engine from Settings (Studio's whisper.cpp install or
Groq), optionally cleans up with Groq/OpenRouter, then pastes (clipboard + PowerShell Ctrl+V) and records
history. Meeting notes record in the main window renderer (mic + loopback system audio, two tracks), and
reuse the same transcription + a summary prompt. Pure logic is unit tested; the pill, history and notes
UIs are Playwright-Electron tested against a mock Groq server (as Studio's AI tests do).

## Global Constraints

- Words are never lost: any failure after recording keeps the audio (Retry) or the raw text.
- Only transcript text goes to the AI provider; audio goes to Groq only if Groq transcription is chosen.
- Defaults: `listen.hotkey` `CommandOrControl+Shift+Space`, `paste: true`, `cleanup: true` (used only when
  the chosen provider has a key), `dictionary: []`, `notesDir` `~/Documents/Leverage Notes`.
- Old settings files load with Listen defaults. Tests never use real keys.

## Review Focus

1. Silence / a cough → nothing pasted, no Whisper call (Task 1).
2. A model that answers a dictated question instead of cleaning it → raw text pasted (Task 2).
3. The user's clipboard is restored only if it still holds our text (Task 3).
4. Hotkey taken → reported like Studio's and Snap's (Task 5).
5. Meeting without system audio (permission / unsupported) → mic-only note with a warning (Task 8).

---

### Task 1: Settings, model, speech gate
- `Settings.listen`; `DictationEntry` / `NoteDoc` schemas in `src/shared/listen.ts`.
- `src/shared/speechGate.ts`: `newGate()`, `addWindow(g, rms, peak)`, `gateDecision(g)` → `{ skip, reason }`
  with OpenWhispr's thresholds (0.002 / 0.003 + 0.02 / 0.006).
- [ ] Tests: settings defaults + old file; gate: silence, a single click, quiet speech, strong speech.

### Task 2: Transcribe text + cleanup
- `whisperTextArgs(engine, wav, prompt)` (entropy 2.8, logprob −1.25, `--prompt`), `transcribeLocalText`;
  `transcribeGroqText(key, file, prompt, fetch)`.
- `buildCleanupPrompt(raw, dictionary)` (transcript in tags, never answer), `pickCleaned(raw, reply)` →
  cleaned text, or raw when the reply is empty, unparseable, or ≥ 2× + 40 chars longer than raw.
- [ ] Tests incl. prompt-injection text staying inside the tags and the "answered instead" guard.

### Task 3: Paste + history
- `pasteText(text, deps)`: save clipboard → write text → wait 40 ms → Ctrl+V → after 500 ms restore only if
  the clipboard still equals text. `deps.sendPaste` = PowerShell on Windows; no-op elsewhere.
- `HistoryStore(file)`: `add`, `list`, `update`, `remove`, `clear`, max 500, corrupt file → empty.
- [ ] Tests with fakes (restore / no-restore / paste disabled) and a temp dir.

### Task 4: Dictation service (main)
- `dictate:*` IPC: `start`/`stop`/`cancel` state machine, `dictate:audio(bytes, gate, durationMs)` →
  convert → transcribe → cleanup → paste → history; failures keep `failed/<id>.webm`; `dictate:retry(id)`.
  Events `dictate:status`, `listen:history`.
- [ ] Unit test of the pipeline with injected transcribe/cleanup/paste fakes.

### Task 5: Hotkey, pill, Listen page (dictation)
- Hotkey toggles; tray item "Dictate"; pill window (non-focusable, bottom-centre of the cursor's display).
- Listen page: Dictation tab — how-to, Paste / Cleanup switches, dictionary editor, history list.
- [ ] e2e: with a mock Groq + fake mic, `dictate:toggle` twice → history shows the text, clipboard holds it.

### Task 6: Notes model + store + summary
- `NotesStore(root)`: create (unique folder), list, get, save (user fields only), remove (trash).
- `buildSummaryPrompt(transcript, notes)`, `parseSummary(reply)` → markdown or `nothing`.
- [ ] Tests.

### Task 7: Notes from Studio recordings
- `notes:fromRecording(id)` uses the recording's transcript (transcribes if missing), summarises.
- Library → recording → "Make notes"; Listen → Notes tab list + note view.
- [ ] e2e with a seeded recording + transcript and a mock Groq summary.

### Task 8: Meeting recording
- Main window: mic + loopback system audio as two MediaRecorders → `notes:chunk` → files in the note folder;
  stop → mix (ffmpeg `amix`) → transcribe → summarise. System audio failing → mic-only + warning.
- [ ] e2e with the fake mic (system audio unavailable on Linux → warning path).

### Task 9: Final review
- [ ] Full unit + e2e, typecheck, lint of new files, docs.
