# Leverage Snap — Implementation Plan

> Steps use checkbox (`- [ ]`) syntax. Build natively with TDD: failing test → implement → pass → commit.

**Goal:** Snap module: hotkey/tray/page capture of a region or full screen, a frozen-screen selection
overlay, a re-editable annotation editor, copy/save/pin, and a gallery.

**Spec:** `docs/superpowers/specs/2026-10-22-snap-design.md`; evidence: `docs/reverse-engineering/02-flameshot.md`.

**Architecture:** Main grabs every display once (`desktopCapturer` thumbnails at native pixels) and keeps
the images in memory; one overlay window per display shows its frozen image (fetched as PNG bytes over
IPC) and returns a selection + action. Main crops with `nativeImage.crop`, stores the shot through
`SnapStore`, and either copies, saves or tells the main window to open the editor. The editor (main
window renderer) keeps a `SnapDoc` (shape list in image pixels), draws with Canvas 2D, and autosaves
the doc and a rendered PNG through IPC. Pure logic (naming, store, selection math, geometry, undo,
pixelation, drawing) is unit tested; UI flows are Playwright-Electron tested with seeded shots.

## Global Constraints

- Same security model as Studio: sandboxed renderers, typed preload API, sender guard.
- Never overwrite a user file; a shot's own rendered PNG is rewritten on edit (it is ours).
- Shapes are stored in original-image pixels; crop is stored, not applied, so it can be undone.
- Undo limit 100. Pixelate never reads interior pixels.
- Default settings: `snap.dir` = `~/Pictures/Leverage`, `snap.hotkey` = `CommandOrControl+Shift+2`.
- No network.

## Review Focus

1. Pixelated area output must not change when the interior pixels change (Task 3 test).
2. 150 % scaling / second monitor: a DIP selection crops the same pixels (Task 5 test).
3. Name collisions / deleted PNG / corrupt `snap.json` never crash the gallery or overwrite (Task 2).
4. Hotkey clash with Studio is reported like Studio's (Task 5).

### Task 1: Shared model + settings

**Interfaces:**
- `Point = { x; y }`; `Shape` union keyed by `kind`: `pen | marker` (`points`), `line | arrow` (`a`, `b`),
  `rect | ellipse` (`rect`, `filled`), `text` (`at`, `text`, `bold`), `counter` (`at`), `pixelate` (`rect`),
  `redact` (`rect`); every shape has `id`, `color`, `size`.
- `SnapDocSchema` = `{ version: 1, id, file, createdAt, width, height, crop?: Rect, shapes: Shape[] }`.
- `SnapEntry = { id, file, createdAt, width, height }`.
- `Settings.snap = { dir: string; hotkey: string }`; old settings files without `snap` load defaults.

- [ ] Tests: `settings.test.ts` (+ snap defaults, partial file keeps snap defaults), `snapDoc.test.ts`
  (valid doc parses, unknown shape kind rejected).
- [ ] Implement; Settings page shows "Screenshots folder" (Change…) and the Snap hotkey.
- [ ] Commit `feat(snap): shot model and settings`.

### Task 2: Naming + SnapStore

**Interfaces:**
- `snapBaseName(d: Date): string` → `2026-10-22_14-05-09`
- `uniquePngName(dir, base): string` → `base.png`, `base (2).png`, … (checks PNG and sidecar folder)
- `class SnapStore(root)`: `create(png: Buffer, size: Size, now?: Date): Promise<SnapDoc>` (writes
  original + rendered copy + snap.json); `list(): Promise<SnapEntry[]>` newest first, skips corrupt /
  PNG-missing entries; `get(id): Promise<SnapDoc | null>`; `save(id, doc, png: Buffer)` (temp + rename);
  `image(id, which: 'original' | 'rendered'): Promise<Buffer>`; `pngPath(id)`; `remove(id)` (via injected trash fn).

- [ ] Tests in a temp dir: names, collision suffixes, create/list/get/save round-trip, corrupt json
  skipped, deleted PNG skipped, `id` with path separators rejected.

### Task 3: Geometry, undo, secure pixelate

**Interfaces:**
- `snapAngle(a, b): Point` (b moved to nearest 45° direction, same length)
- `arrowGeometry(a, b, size): { shaftEnd: Point; head: [Point, Point, Point] }` (head length `18 + 4s`,
  width `10 + 2s`, capped at 60 % of the arrow length; tip = `b`)
- `shapeBounds(shape, measure?): Rect`, `hitTest(shapes, p, tol): string | null` (topmost),
  `moveShape(shape, dx, dy): Shape`, `counterNumbers(shapes): Map<string, number>`
- `class UndoStack<T>(initial, limit = 100)`: `current`, `push(next)`, `undo()`, `redo()`, `canUndo`, `canRedo`
- `pseudoPixelate(img: { data: Uint8ClampedArray; width; height }, rect: Rect, block: number): Uint8ClampedArray`
  (RGBA for `rect`, only reading the 1-px fringe around it; deterministic)

- [ ] Tests incl. **interior independence**: two images differing only inside the rect → identical output.
- [ ] Commit `feat(snap): annotation geometry, undo, secure pixelate`.
